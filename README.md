### 👋 About

I build small, focused software that people actually use: fast websites for local businesses,
useful web apps that solve one problem well, and browser games that run instantly with no download.

### 🛠️ What I can build for you

- **Business websites:** shops, restaurants, salons, services. Mobile-first and easy to find on Google.
- **Web apps & tools:** planners, calculators, dashboards, booking tools.
- **Browser games:** quick, fun, shareable. Good for promotions, events or just for fun.
- **Fixes & redesigns:** faster, cleaner and working on phones.
